#  Curso de HTML y CSS para Estudiantes de Secundaria

## 📋 Información del Curso

**Nombre del repositorio:** `DiabeLife-Html-Css`  
**Organización:** DiabeLife-Course-Html-Css  
**Público objetivo:** Estudiantes de secundaria (12-17 años)  
**Duración total:** Aproximadamente 1 hora   
**Modalidad:** Videos de YouTube no listados + Editores online  

## 🎯 Objetivo del Curso

Este curso introduce a estudiantes de secundaria a los conceptos fundamentales del desarrollo web usando HTML y CSS. A través del proyecto DiabeLife, una aplicación web sobre el manejo de la diabetes, los estudiantes aprenderán a crear sitios web modernos y funcionales mientras adquieren conciencia sobre temas importantes de salud.

## 🌟 Por qué es Llamativo (12-17 años)

- **Temática de Salud Moderna:** Creación de una app web sobre diabetes que simula aplicaciones reales de salud
- **Diseño Visual Atractivo:** Los estudiantes ven cómo HTML estructura el contenido y CSS lo hace hermoso
- **Progresión Práctica:** Desde una página básica hasta un sitio completo con navegación y estilos avanzados
- **Relevancia Social:** Aprenden sobre un tema de salud importante mientras programan
- **Sin Instalaciones:** Todo funciona 100% online usando editores web

## 📚 Secuencia de Lecciones

### Lección 2: Tu Primera Página Web 
**Conceptos:** Estructura básica de HTML, etiquetas fundamentales, semántica

Aprende qué es HTML y cómo crear tu primera página web. Crearemos la estructura básica de DiabeLife con títulos, párrafos y la información principal sobre diabetes.

---

### Lección 3: Navegación y Enlaces
**Conceptos:** Enlaces, navegación, listas, imágenes, estructura de sitio web

Expandiremos DiabeLife agregando un menú de navegación, enlaces entre páginas y contenido multimedia. Los estudiantes aprenderán a organizar un sitio web completo.

---

### Lección 4: Dale Estilo a tu Web
**Conceptos:** CSS básico, selectores, propiedades de texto, colores, fondos

Introducción al CSS para transformar nuestra página HTML básica en algo visualmente atractivo. Aprenderemos a cambiar colores, fuentes y fondos para hacer DiabeLife más profesional.

---

### Lección 5: Diseño Responsivo y Layout
**Conceptos:** CSS avanzado, flexbox/grid, diseño responsivo, media queries

Haremos que DiabeLife se vea bien en todos los dispositivos. Aprenderemos técnicas modernas de layout para crear una experiencia de usuario completa y profesional.

---

### Proyecto Final: DiabeLife Completo
**Conceptos:** Integración completa, mejores prácticas, optimización, proyecto real

Uniremos todo el conocimiento para completar DiabeLife: una aplicación web funcional con múltiples páginas, navegación fluida, diseño responsivo y contenido educativo sobre diabetes. El proyecto final incluirá formularios, galerías y secciones informativas.

---

## 🚀 Tecnologías Utilizadas

- **HTML5:** Estructura y contenido semántico
- **CSS3:** Estilos, animaciones y diseño responsivo
- **Editores Online:** CodePen, JSFiddle o similares para práctica inmediata

## 📱 Características del Proyecto Final

- ✅ Sitio web multi-página sobre manejo de diabetes
- ✅ Diseño responsivo (móvil, tablet, desktop)
- ✅ Navegación intuitiva y accesible
- ✅ Contenido educativo y visualmente atractivo
- ✅ Formularios interactivos
- ✅ Galería de imágenes
- ✅ Información médica organizada y clara

## 🎓 Habilidades que Desarrollarás

- Estructura de documentos web con HTML semántico
- Estilizado profesional con CSS
- Principios de diseño web responsivo
- Mejores prácticas de desarrollo frontend
